<h2 align="center">Tree</h2>

- **Hyprland — Desktop Environment:**
    - **[Hyprland](https://github.com/xscriptor-colors/hyprland)**: A clean, performance-oriented Hyprland configuration with **[QuickShell](https://github.com/quick-shell/quick-shell)** QML shell and Matugen dynamic theming, optimized for Arch Linux and X Linux.

- **X Linux — Distribution/Spin:**
    - **[X Linux](https://github.com/xscriptor/x-linux)**: Custom Arch Linux spin focused on simplicity, clean X branding, and reproducible builds. Ships its own package repository via **[x-repo](https://github.com/xscriptor/x-repo)**.

    - **[X Scripts](https://github.com/xscriptor/x)**: Entrypoint script that installs the `x` wrapper, configures Zsh + Oh My Zsh, applies shell aliases, and sets up packages across supported distros.

    - **[Xpm](https://github.com/xscriptor/xpm)** / **[Xpkg](https://github.com/xscriptor/xpkg)**: X Package Manager and packer for the X Linux ecosystem.

- **Terminal — Shell & Apps:**
    - **[Terminal Themes](https://github.com/xscriptor-colors/terminal)**: Twelve custom themes adapted for 26+ terminals (Kitty, Alacritty, WezTerm, Ghostty, iTerm2, and more) across all platforms.

    - Terminal Apps:
        - **[Xfetch](https://github.com/xscriptor/xfetch)**: a fast, lightweight system info fetcher for the terminal, built in Rust.
        - **[Xtop](https://github.com/xscriptor/xtop)**: a modern cross-platform TUI system monitor written in Rust, inspired by btop.
        - **[Xclock](https://github.com/xscriptor/xclock)**: a terminal-based clock with ASCII art, countdown timers, and customizable time zones.
        - **[GitNapse](https://github.com/xscriptor/gitnapse)**: an interactive TUI tool for efficient Git repository exploration and management.

- **Visuals — Wallpapers & Assets:**
    - **[Xwall](https://github.com/xscriptor/xwall)**: interactive web app to generate fluid, aesthetic 4k wallpapers for Hyprland and beyond.

- **Editors & IDEs:**
    - **[Neovim](https://github.com/xscriptor-colors/nvim)**: X-configured Neovim setup.
    - **[VS Code](https://github.com/xscriptor-colors/vscode)**: themes (Xscriptor, X-Dark-Colors) and extensions (XGlass).
    - **[JetBrains](https://github.com/xscriptor-colors/jetbrains)**: settings and customizations for JetBrains IDEs.
    - **[Obsidian](https://github.com/xscriptor-colors/obsidian)**: elegant Obsidian theme with EB Garamond typography.
