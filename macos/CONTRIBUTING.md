# Contributing to macOS Xscriptor

Thank you for considering contributing. To maintain quality, please follow these guidelines.

## How to Contribute
1. **Fork** the repository.
2. **Create a branch** for your feature or fix (`git checkout -b feat/amazing-feature`).
3. **Commit** your changes.
4. **Push** to your branch and open a **Pull Request**.

## Structure
- `sketchybar/`: SketchyBar bar config, items, plugins, colors, and icons (Bash).
- `aerospace/`: AeroSpace tiling window manager config (TOML).

## Rules
- Respect the **Code of Conduct**.
- Do not include personal or machine-specific paths in PRs (e.g., absolute home paths).
- Test your changes before opening a PR.
- For security vulnerabilities, please open a private issue.
